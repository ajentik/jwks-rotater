# Security Policy

## Supported Versions

The operator is pre-1.0. We currently support the latest minor release on
`main`. Older tags do not receive security backports.

| Version | Supported |
|---------|-----------|
| latest `main` | yes |
| < latest      | no  |

## Reporting a Vulnerability

Please **do not** open a public issue for security vulnerabilities.

Report privately via GitHub's [Private vulnerability reporting](https://github.com/ajentik/jwks-rotater/security/advisories/new)
form. We will acknowledge receipt within 5 business days and aim to provide
a remediation plan within 14 days for confirmed issues.

When reporting, please include:

- A description of the vulnerability and its impact
- Steps to reproduce (proof-of-concept if possible)
- The affected version or commit SHA
- Any suggested mitigation
