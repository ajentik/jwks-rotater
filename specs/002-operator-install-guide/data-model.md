# Data Model: Operator Installation Guide

This feature produces documentation and build artifacts rather than runtime data structures. The "data model" describes the deliverable artifacts, their structure, and relationships.

## Deliverable Artifacts

The consolidated Kubernetes manifest file generated by `make build-installer`.

| Section | Contents | Source |

## Relationships

```text
Makefile (IMG default)
  └── make build-installer
       └── dist/install.yaml (generated artifact)
            └── Referenced in docs/install.md "Quick Install" section
                 └── Linked from README.md "Installation" section
```

## Validation Rules

- `dist/install.yaml` MUST be valid YAML that `kubectl apply -f` accepts without errors
- `dist/install.yaml` MUST contain a valid image reference (not the placeholder `controller:latest`)
- `docs/install.md` MUST reference the correct namespace (`jwks-rotater-system`)
- `docs/install.md` MUST reference the correct image (`ghcr.io/yanok/jwks-rotater:latest`)
- README "Installation" section MUST link to `docs/install.md` using a relative path
